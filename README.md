# BLACKWOOD BARBER — მუშა WhatsApp ვერსია

HTML5, CSS3, Vanilla JavaScript. GitHub Pages-ზე გამოქვეყნებული სტატიკური საიტი.

## მოთხოვნის გზა

მომხმარებელი ავსებს სახელს, სერვისს, სასურველ თარიღს და სურვილისამებრ საათსა და საკონტაქტო ნომერს. გვერდი აჩვენებს მომზადებულ ტექსტს. „გაგზავნა WhatsApp-ით“ ხსნის მიმღების ჩატს; გაგზავნას მომხმარებელი WhatsApp-ში თავად ადასტურებს. ვიზიტი მხოლოდ მიმოწერაში შეთანხმების შემდეგ დასტურდება. საიტი თავისუფალ საათებს არ ამოწმებს და შეტყობინების რეალურ გაგზავნას ვერ აკვირდება.

- ნომერი: `WHATSAPP_NUMBER` ცვლადი `js/script.js`-ში, საერთაშორისო ფორმატში მხოლოდ ციფრებით. ნომრის შეცვლისას განაახლე სტატიკური WhatsApp ბმულები და ხილული ნომერიც `index.html`-ში.
- მოთხოვნის ტექსტი, ქართული თარიღი, სურვილისამებრ საათი, ტექსტის კოპირება და რედაქტირება.
- მონაცემები არ ინახება საიტის ბაზაში. ფანჯრის დახურვა ასუფთავებს ფორმასა და პერსონალიზებულ ბმულს. WhatsApp ბმულის გახსნა მისამართში გადასცემს მომზადებულ ტექსტს WhatsApp-ს.
- არ არის backend, API გასაღები ან გადახდის სისტემა.
- ყველა ფოტო და ქართული შრიფტი ლოკალურია.
- გამოგონილი შეფასებები და უმოქმედო Instagram ღილაკები ამოღებულია; მათ ადგილას პრაქტიკული FAQ-ია.

## ბიზნესის სტატუსი

ბრენდი, გუნდი, ფასები და მდებარეობა კვლავ პორტფოლიოს საილუსტრაციო მონაცემებია. არ წარმოადგენს რეალურად გახსნილ სალონს. WhatsApp-ის ნომერი მომხმარებელმა მიმღებად თავად მიუთითა და ის მოქმედია მოთხოვნების მიღებისთვის. რეალური მისამართი უცნობია და არ არის გამოგონილი მოქმედი მისამართით წარმოდგენილი.

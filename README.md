# BLACKWOOD BARBER — ქართული სატესტო ვერსია

სტატიკური HTML5/CSS3/Vanilla JavaScript ბარბერშოპის ვებსაიტი. გამოგონილი ბრენდი, პერსონალი, მისამართი, შეფასებები და საილუსტრაციო ფასები. **WhatsApp-ის მიმღები რეალური სატესტო ნომერია, რომელიც მფლობელმა მიუთითა.**

## როგორ მუშაობს მოთხოვნა

1. მომხმარებელი ირჩევს სერვისს და ავსებს სახელს, სასურველ თარიღსა და სურვილისამებრ საკონტაქტო ნომერს.
2. „WhatsApp ტექსტის მომზადება“ მხოლოდ გვერდზე აჩვენებს მოთხოვნის სრულ ტექსტს. აქ არაფერი გაგზავნილა.
3. „WhatsApp-ში გახსნა“ ხსნის მიმღების ჩატს მომზადებული ტექსტით.
4. მომხმარებელი შეტყობინებას **WhatsApp-ში თვითონ აგზავნის**. საჭიროა WhatsApp ანგარიში; კომპიუტერზე შესაძლებელია WhatsApp Web-ში შესვლა.
5. მფლობელი და მომხმარებელი ცალკე ათანხმებენ დროსა და ფასს. ვებსაიტი ხელმისაწვდომობას არ ამოწმებს და ჯავშანს არ ადასტურებს.

შესაძლებელია ტექსტის რედაქტირებისთვის ფორმაზე დაბრუნება ან კოპირება. ფანჯრის დახურვა ასუფთავებს ფორმას, მომზადებულ ტექსტსა და პერსონალიზებულ ბმულს. საიტი ფორმის მონაცემებს არ ინახავს. მომხმარებლის მიერ WhatsApp ბმულზე დაჭერის შემდეგ ტექსტი გადაეცემა WhatsApp-ს; მის დამუშავებაზე ვრცელდება WhatsApp-ის წესები. მფლობელი მოთხოვნას მხოლოდ WhatsApp-ში გაგზავნის შემდეგ ნახავს.

## კონფიგურაცია

`dist/js/script.js`-ში `WHATSAPP_NUMBER` არის საერთაშორისო ნომერი მხოლოდ ციფრებით, `+`-ისა და გამოტოვებების გარეშე. ნომერი ვებსაიტის ღია კონფიგურაციაა; ის საიდუმლო არ არის. ზოგადი WhatsApp ბმულების მისამართები `dist/index.html`-შიც განაახლე ნომრის შეცვლისას.

## GitHub Pages-ის პაკეტი

მომხმარებლის ZIP-ში `index.html`, `css/`, `js/`, `assets/` და `.nojekyll` პირდაპირ მთავარ დონეზეა. ამ ფაილების ატვირთვა და GitHub Pages-ის ჩართვა საკმარისია საიტისა და WhatsApp გზის მუშაობისთვის. backend, build ან გადახდის სისტემა არ არის საჭირო.

Sites-ის source checkout-ში იგივე ვებსაიტის ფაილები `dist/` საქაღალდეშია, ხოლო `.openai/hosting.json` მიუთითებს ამ საქაღალდეს.
